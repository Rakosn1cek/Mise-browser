What's New in Mise v1.8.1

The v1.8.0 Media Offload, Zero-Cloud Mobility, Resource Inspection & Security Hardening Milestone: Hardware-accelerated mpv media offload, Zero-Cloud Send to Mobile SVG QR code generation, Linux procfs Task Manager overlay, background delta updates, collapsible workspace dashboard nodes, webview zoom controls, smooth scrolling toggle, history privacy controls with single-item deletion, and four-phase defence-in-depth security hardening.

Low-Resource Media Offload (mpv & yt-dlp)

Offload video streams directly to external native mpv player instances using yt-dlp stream extraction, eliminating heavy Chromium decoding overhead.

  • Hardware Video Acceleration: Bypasses browser media pipeline in favour of native VA-API / VDPAU acceleration on Linux, saving significant CPU cycles and memory on fanless hardware.
  • Instant Keyboard & Status Bar Offload: Press Ctrl + Shift + Y to offload active video streams immediately, or click the blue MPV status bar badge.
  • Context Menu Stream Routing: Right-click video links or thumbnails to launch mpv directly without loading the web page, with automatic tab pausing to eliminate dual playback.

Send to Mobile (Zero-Cloud QR Code)

Transfer URLs directly to mobile devices without cloud relays, accounts, or telemetry using an embedded pure vanilla SVG generator.

  • Zero-Cloud Privacy: Pure ISO/IEC 18004 SVG matrix encoding executed entirely on-device, communicating with zero external network APIs.
  • Instant Modal Access: Press Ctrl + Shift + M or click the status bar QR badge to display crisp high-contrast codes scan-ready for phone cameras.
  • Modal Lifecycle: Instant dismissal via Escape with automatic focus restoration back to the active tab.

Task Manager & Tab Resource Inspector

Kernel-level Linux resource inspection overlay revealing exact physical RAM (PSS, RSS, USS) and live CPU percentage per tab.

  • Precise procfs Accounting: Computes accurate memory metrics directly from /proc/[pid]/smaps_rollup, eliminating shared library duplication errors.
  • Multi-Workspace Overview: Keyboard-driven overlay (Ctrl + Shift + T) grouping processes by workspace with category filters (All, Active, Sleeping, Background).
  • Surgical Process Management: Terminate runaway renderer processes or trigger instant tab hibernation directly from the inspector interface.

Background Delta Updates & Engine Enhancements

Silent differential updates via electron-updater and upgraded engine runtime components.

  • Differential Delta Streaming: Streams compact binary delta patches in the background for Linux AppImage (zsync), Windows NSIS, and macOS.
  • Non-Intrusive Readiness Pill: Displays a discreet status bar indicator ([⟳ Restart to update]) when an update is fully staged, applying on click.
  • Engine Upgrades: Upgraded to Electron v45.4.1 (Chromium 156) with extensive zero-copy GPU flags and expanded disk and media caching.

Workspace Dashboard Collapsible Nodes & Visual Identity

Streamlined multi-workspace management with compact tree nodes, tab count badges, and persistent expansion state.

  • Collapsible Tree Hierarchy: Large workspace sessions remain compact; inactive workspaces start collapsed with count badges (e.g. 8 tabs), expanding via Space or arrow keys.
  • Session Memory: Expanded and collapsed states persist across dashboard toggles for the duration of the browser session.
  • Container Isolation: Header tags display container partitions (persist:work, volatile) alongside live cookie counts and surgical container wiping.

Webview Zoom Controls & Media Deduplication

Precise per-tab magnification controls and cleaner navigation when opening web media.

  • Granular Zoom Scaling: Zoom in Ctrl + =, zoom out Ctrl + -, and reset Ctrl + 0 between 50% and 300% with live factor toasts.
  • Direct Media Loading: Suppresses self-referencing duplicate tabs and bypasses interstitial HTML wrappers when opening direct images or media links.

History Privacy Controls & Smooth Scrolling

Enhanced browsing privacy options, granular history management, and custom scrolling dynamics.

  • Keep History Toggle: Pause future visit logging in Preferences without purging existing records; private workspaces and peek modals remain unconditionally excluded.
  • Single-Item History Deletion: Delete individual history entries with x or Delete alongside full database purges.
  • Kinetic Smooth Scrolling: Optional engine-level smooth scrolling toggle in Preferences for touchpad and mouse navigation.

Four-Phase Security Hardening Audit

Comprehensive defence-in-depth hardening across four audited security phases:

  • Phase 1: Sensitive token and credential scrubbing from URLs, checkout hijacking prevention, fail-closed userscript permissions, and private workspace storage isolation.
  • Phase 2: Payment and PIN input element detection, query-distinct popup isolation, guest session scoping for saved images, canvas fingerprinting jitter, and TLS exception subframe isolation.
  • Phase 3: Canonical path validation with PDF symlink traversal blocking, comprehensive domain and workspace storage wiping, cross-origin Referer truncation and protocol downgrade stripping, race-free ephemeral webview tagging, and private profile spellchecker network isolation.
  • Phase 4: Elimination of redundant IPC channels, dead code cleanup, and complete synchronisation between runtime checks and documentation.
