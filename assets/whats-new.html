What's New in Mise v0.14.0

Authentication compatibility, dynamic keyboard layout prioritisation, main-process memory compaction, and desktop window controls.

🔐

Authentication Compatibility & Scriptlet Isolation

Streamlined identity authentication across modern service platforms whilst sustaining rigorous tracking protection.

  • Bypassed intrusive ad-blocker scriptlets on x.com and twitter.com to allow credential verification without false rejections.
  • Standardised baseline Chromium User-Agent fallback to eliminate runtime token leakage across renderers and worker threads.
  • Preserved network-layer ad and tracker blocking without interfering with client integrity verification.
⌨️

Dynamic Keyboard Layout Prioritisation

First-class ergonomics for Dvorak, AZERTY, and international keyboard configurations.

  • Alphabetical shortcuts and command chords now evaluate active layout glyphs rather than raw physical positions.
  • Classic QWERTY scan-code fallbacks remain fully operational for international and non-Latin character sets.
  • Seamless typing and navigation harmony across multilingual desktop environments.
🧠

Main-Process V8 Compaction & Uncapped Headroom

Hardened garbage collection orchestration and lifted renderer memory ceilings.

  • Restored proactive main-process V8 heap compaction on tab hibernation without exposing runtime flags to untrusted content.
  • Removed the 512 MB renderer heap ceiling, preventing crashes on heavy single-page web applications and large spreadsheets.
  • Refined memory footprint across long-running browser sessions on resource-constrained Linux setups.
🪟

Desktop Window Controls & Tab Synchronisation

Enhanced usability on traditional desktop environments alongside reliable tab state tracking.

  • Optional sidebar window controls (minimise, maximise, close) for seamless integration with GNOME, KDE Plasma, and XFCE.
  • Multi-event tab title synchronisation resolving intermittent loading placeholders across asynchronous page transitions.
  • Runtime upgrade to Electron v44.7.0 powered by Chromium 152 and Node.js 24.
