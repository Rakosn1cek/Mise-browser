What's New in Mise v1.3.0

The v1.3.0 Centred Omnibar & Defence-in-Depth Update: Fixed status bar address bar with upward suggestions, rigorous IPC host sender verification across all handlers, hardened userscript bridge security and storage quotas, community feedback integration, and upstream dependency patches.

Fixed Centred Status Bar Address Bar

The Wide Address Bar is now natively integrated into the fixed 28px bottom status bar, preserving a 100% uncluttered browsing canvas.

  • Relocated the omnibar directly into the status bar centre with responsive proportional sizing.
  • Upward suggestions pop-up overlay (#AddressSuggestions) presenting instant search aliases, quickmarks, and history completions.
  • Preserves full Vim normal mode shortcut integration: press Ctrl + L or ! to focus and begin navigating immediately.
  • Refined border radii and auto-collapse sidebar stacking order ensuring smooth visual transitions.

IPC Defence-in-Depth & Host Sender Verification

Comprehensive multi-layer isolation ensuring privileged main process capabilities cannot be invoked by untrusted guest webview content.

  • Strict host sender verification on all ipcMain handlers: requests originating from guest webview frames are actively intercepted and denied.
  • Input validation and bounding: diagnostics payloads bounded to depth 6 and capped strings to prevent memory exhaustion.
  • Configuration safety: partial configuration updates validated against strict schemas, rejecting unrecognised keys and malicious URL schemes.
  • Session persistence safeguards: session saving rejects malformed payloads and limits snapshot rotation.

Hardened Userscript Sandbox & Storage Quotas

Engineered robust lifecycle protections and storage boundaries for local userscripts and user styles.

  • Dynamic token lifecycle: userscript API bridge tokens expire on idle and enforce capacity limits.
  • Strict sender binding: tokens are bound to the initial sender and main frame, revoking immediately upon navigation.
  • Storage safety: 1 MB persistent storage quota per script with atomic file persistence and write debouncing.
  • Style query isolation: CSS extractions proceed cleanly without minting unnecessary privileged userscript tokens.

Community Dialogue & Upstream Security Patches

Strengthened upstream dependencies and integrated community collaboration tools directly into the browser workflow.

  • Upgraded upstream dependencies: bumped fast-uri to 3.1.9 and undici to 7.30.1 and 6.29.1.
  • Command Palette integration: jump directly to GitHub Discussions or report issues via searchable commands in Ctrl + P.
  • All 56 automated test suites passing with 100% verification across security, UI, and storage modules.

Your Voice Shapes Mise

Mise collects zero telemetry and never tracks your browsing. Because we do not monitor you, your direct feedback is the only way we know how the browser performs across different Linux distributions and desktop setups.
