What's New in Mise v1.5.0

The v1.5.0 Architecture & Keyboard Polish Update: Codebase modularisation across stylesheets, renderer controllers, and webview managers, alongside hardened keyboard navigation, overlay focus trapping, direct webview navigation dispatch, and expanded automated test verification.

Codebase Modularisation & Vanilla Architecture

Comprehensive architectural refactoring decomposing monolithic files into clean, specialised domain modules without bundler overhead.

  • Stylesheet Modularisation: Decomposed monolithic style.css (reduced from 4,845 lines to a 9-line master aggregator) into domain-specific modules under styles/ and 8 dedicated overlay sheets under styles/overlays/ using native CSS imports.
  • Renderer Process Modularisation: Decomposed monolithic renderer.js (reduced from 1,407 lines to a 249-line entry orchestrator) into 5 specialised ES controllers under modules/renderer/ for browser initialisation, sidebar controls, workspaces, theming, and in-page search.
  • Webview Subsystem Modularisation: Extracted webview tab lifecycle, split view, memory sleep management, and audio control into discrete controllers under modules/webview/.
  • Zero Runtime Overhead: Preserved pure vanilla ES modules and standard CSS without bundlers, maintaining ultra-low CPU and memory footprints.

Overlay Keyboard Trapping & Navigation Polish

Hardened keyboard focus loops, robust keyboard traversal, and layout stability across all full-page overlays.

  • Command Palette Navigation: Fixed category filter chip jitter with stable layout rules. Arrow keys cycle through filter chips and commands cleanly, whilst circular Tab trapping ensures focus never escapes the palette.
  • Notes Overlay Focus Trapping: Webviews are safely hidden on open, Tab and Shift + Tab cycle strictly through all note controls without focus leakage, Enter toggles edit mode or clicks actions, and Escape cleans up state upon dismissal.
  • Workspace Dashboard Navigation: Full keyboard navigation across workspace cards, direct delete button delegation with safe fallback protection to prevent accidental deletion of active or default workspaces.
  • Workspace Palette Commands: Added dedicated Command Palette actions under a new "Workspaces & Dashboard" category to create, rename, and delete workspaces directly.

Direct Webview Navigation & Visual Feedback

Instantaneous navigation dispatch, responsive loading states, and automatic keyboard focus return.

  • Direct Webview Navigation API: Upgraded address bar submission to trigger native webview loadURL() alongside src attribute updates, guaranteeing immediate navigation dispatch.
  • Immediate Tab Loading Feedback: Actively updates the active tab label in the sidebar with the target host and a "Loading..." indicator upon submission so navigation dispatch is visibly acknowledged.
  • Webview Focus Restoration: Automatically restores keyboard focus to the active guest webview after address bar submission and Escape cancellation, enabling immediate Vim normal-mode shortcuts (f, j, k) without mouse clicks.
  • Status Bar Mode Synchronisation: Real-time synchronisation of the status bar mode indicator with link hint overlay activation.

Expanded Automated Regression Suite

Comprehensive automated test verification protecting stability, architecture boundaries, and user interactions.

  • Expanded test coverage to 70 comprehensive test suites, all passing with 100% verification across security, storage, navigation, and modular controllers.
  • Strict architectural guardrails verified in tests, ensuring renderer line budget caps, master stylesheet import integrity, and anti-pastejacking barriers remain inviolate.

Your Voice Shapes Mise

Mise collects zero telemetry and never tracks your browsing. Because we do not monitor you, your direct feedback is the only way we know how the browser performs across different Linux distributions and desktop setups.
