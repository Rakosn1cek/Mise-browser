What's New in Mise v1.7.2

The v1.7.0 Linux Packaging, Modal Workflow & Container Privacy Milestone: Native AppStream metadata and verified AppImageHub packaging, automated Widevine DRM detection, unified Notifications and Activity overlay, ephemeral tab peek link preview, floating Tokyo Night find-in-page match counter, per-workspace visual identity customisation, consolidated modal keybindings, granular domain permissions vault, and configurable local document viewing.

Linux Packaging, AppStream Metadata & Widevine DRM

Comprehensive native Linux distribution readiness, verified AppStream metadata, and automated Widevine DRM media detection.

  • Desktop AppStore Metadata: Bundles verified Freedesktop AppStream metainfo (io.github.rakosn1cek.mise-browser.metainfo.xml) compliant with OARS 1.1 ratings, Tokyo Night brand colours, and rich screenshots for Linux software centres (GNOME Software, KDE Discover).
  • AppImageHub Packaging Verification: Pure Zsh validation tooling (scripts/prepare-appimagehub.zsh) automated for directory submission and metadata validation.
  • Widevine DRM Detection Helper: Automated detection and registration for host Widevine CDM libraries (libwidevinecdm.so) from Chrome, Chromium, and system packages, enabling protected media playback on Linux with privacy-scrubbed diagnostics.

Notifications & Activity Overlay

Dedicated keyboard-driven overlay (Ctrl + Shift + N) centralising recent browser events, active downloads, system updates, and alerts in one unified place.

  • Unified Alert Centre: Quick access from the keyboard (Ctrl + Shift + N) or sidebar bell button to review downloads, system updates, and permission prompts.
  • Category Filtering & Memory Bounds: Instant filter chips (All, Downloads, System, Web) backed by an in-memory 50-event circular buffer to prevent resident memory growth.
  • Keyboard Navigation & Focus Restoration: Arrow cursor traversal, single-key item dismissal (x), clear-all action (c), and seamless webview focus restoration on Escape.

Ephemeral Tab Peek ("Glance") & Find-in-Page Counter

Keyboard-driven link previews and upgraded in-page search controls styled in Tokyo Night.

  • Ephemeral Tab Peek: Transient link preview modal (Shift + Click or gh hint) over the active tab, dismissing instantly on Escape without leaving tab clutter or promoting to a permanent tab with Ctrl + Enter.
  • Find-in-Page Match Counter: Floating Tokyo Night search bar (Ctrl + Shift + F or /) with live match counters (e.g. 4 of 21 matches) and Vim-style n (next) and N (previous) navigation.

Workspace Visual Identity & Accent Badges

Granular visual customisation across workspaces to distinguish container profiles instantly in the sidebar.

  • Curated Tokyo Night Palette: Choose from 9 curated palette accents or assign custom hex colours directly in the Workspace Dashboard.
  • Single-Character Glyph Badges: Personalise workspaces with single-character Unicode glyphs and emoji, segmented via native grapheme clustering.
  • Zero-Trust Sanitisation: Strict hex regex validation, BiDi override stripping, and unforgeable Private profile immunity.

Keybindings Consolidation & Permissions Vault

Streamlined modal keyboard controls alongside granular domain hardware permission auditing and revoking.

  • Consolidated Keybindings: Enforced a strict maximum of two bindings per action (one primary chord and one Vim-style keybind), eliminating redundant bindings and modal traps.
  • Domain Permissions Vault: Inspect and revoke camera, microphone, geolocation, and clipboard access per domain in Preferences and the status bar, backed by an unconditional Zero-Trust sensor lockdown in Private Profile.
  • Configurable Local Document Viewing: Opt-in Zero-Trust toggle in Preferences enabling safe viewing of offline documents (.html, .txt, .svg) with strict path sanitisation and system directory confinement.
  • Engine Upgrades & Verification: Upgraded to Electron v45.3.1 with 82 automated regression test suites verifying stability, memory isolation, and security.
