What's New in Mise v1.1.0

The v1.1.0 Architecture & Ergonomics Update: Modular main process, History overlay keyboard overhaul with instant Escape dismissal, compositor memory optimisations, and expanded 21-suite test harness.

Modular Main Process Architecture

The Electron main process has been re-architected following the orchestrator pattern, significantly reducing cognitive load and simplifying long-term maintenance.

  • Subsystems extracted into dedicated modules: downloads & file manager integration (main/downloads.js), atomic configuration store (main/config.js), session persistence & crash sentinels (main/sessionStore.js), local data & bookmarks (main/storage.js), and release updates (main/updater.js).
  • 40% line reduction in main.js (from 2,106 to 1,262 lines) with zero regressions across core browser workflows.
  • Sacred boundaries preserved: True Tab Hibernation, hardened Chromium engine switches, and isolated multi-account container partitions remain strictly protected.

History Overlay Keyboard Overhaul & Instant Dismissal

Complete keyboard-driven ergonomics for the History overlay, eliminating the need to reach for a trackpad or press Tab repeatedly to close the view.

  • Instant Escape dismissal with capturing event listeners: closes the overlay immediately even when the search input field is actively focused.
  • Seamless home-row navigation: traverse visited entries using ArrowDown and ArrowUp with cyclic boundary wrapping.
  • Visual Tokyo Night accent selection styling (border-left: 3px solid #7aa2f7) and instant Enter key activation to spawn selected URLs into new workspace tabs.
  • Accessible focus trap cycling strictly between the search input, purge button, and close button without leaking focus out to the vertical sidebar.

Compositor GPU Memory Capping

Targeted memory bounds engineered specifically for fanless Linux devices, older laptops, and resource-constrained environments.

  • Compositor texture memory allocation capped at 512MB, preventing GPU memory exhaustion and compositor crashes on media-heavy pages.
  • Reinforces True Tab Hibernation by keeping baseline graphics memory low during intensive browsing sessions.
  • Early boot switches guarantee memory limits are applied before Chromium renderers initialise.

Expanded 21-Suite Automated Regression Harness

Rigorous automated verification guaranteeing architectural stability across every subsystem.

  • Four new dedicated test suites added: tests/downloads.test.js, tests/storage.test.js, tests/updater.test.js, and tests/history-overlay.test.js.
  • Complete headless verification of atomic file swaps, visit deduplication, semantic version comparisons, and overlay keyboard navigation.
  • 100% pass rate across all 21 test suites in under 10 seconds.
