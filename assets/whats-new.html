What's New in Mise v1.0.0

The v1.0.0 Milestone: True tab hibernation, 1x2 dual-split view, container-isolated workspaces, native user scripts, and keyboard-centric web navigation.

True Tab Hibernation & Memory Conservation

Engineered specifically for fanless Linux hardware and low-resource devices, Mise achieves dramatic memory savings without losing state.

  • Inactive background tabs detach entirely from the DOM across all workspaces, terminating idle Chromium renderer processes and reducing RAM usage by 60% or more.
  • Live URLs, titles, and exact scroll positions are preserved and restored smoothly on demand upon tab selection.
  • Safe hibernation startup mode guards against sudden memory pressure and kernel OOM panics when launching large saved sessions.

1x2 Dual-Split View & Isolated Container Partitions

Browse side-by-side with independent navigation and maintain strict privacy boundaries between different accounts and tasks.

  • Toggle dual-split view instantly via Ctrl + Shift + S to inspect reference documents, compare web pages, or cross-reference research.
  • Swap pane positions (Ctrl + \) and adjust partition ratios with intuitive keyboard controls.
  • Each workspace runs in its own dedicated Chromium partition store (persist:work, persist:personal), preventing cookie cross-contamination across accounts.

Mouse-Free Navigation, Search Aliases & Bangs

Keep your hands on the home row with a complete suite of Vim-inspired navigation keys, link hints, and address bar shortcuts.

  • Link Hints (f) highlight clickable targets with two-letter tags for lightning-fast, mouse-free page interaction.
  • Built-in search engine aliases and bangs: quick prefixes like g, !ddg, yt, gh, aur, pkg, so, r, sp, b, and k.
  • Direct tab jumping (Ctrl + 1 to Ctrl + 9), floating omnibar (Ctrl + L / o), and fully customisable shortcuts via keybinds.json.

Markdown Scratchpad & Reader View Export

Integrated knowledge management tools designed for research, reading, and personal note-taking workflows.

  • Instant Markdown quick notes (Ctrl + N) with full canvas toggle (f) and live word counters.
  • Export clean distilled articles from Reader View directly into Quick Notes via Ctrl + Shift + E complete with YAML frontmatter.
  • Context menu web clipping: highlight any web text, right-click, and select "Save to Notes".
  • Launcher buttons to open notes directly inside your favourite external vault editors: Obsidian, Neovim, and Logseq.

Pinned Tabs, Audio Controls & Crash Safety

Robust tab management, granular media controls, and atomic POSIX file safety for bulletproof daily browsing.

  • Dock essential communication channels and tools via Ctrl + Shift + X or Normal mode p, protected against accidental closure.
  • Per-tab audio indicators with direct mute toggles (Ctrl + Shift + M) and global audio mute (M).
  • Atomic configuration and session writes via temporary staging and rename swaps eliminate the risk of corrupted state during abrupt shutdowns.
