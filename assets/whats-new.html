What's New in Mise v1.2.0

The v1.2.0 Security & Private Workspace Update: Permanent isolated Private workspace with zero disk persistence, four-phase security hardening overhaul, Electron v45.0.0 runtime modernisation, session snapshot rotation, and 52-suite test harness.

Permanent Isolated Private Workspace

A built-in, dedicated Private workspace bound to volatile memory with complete data boundary isolation.

  • Ephemeral session partition (persist:workspace_private) ensuring cookies, localStorage, and network caches are purged upon closure.
  • Zero disk persistence: private tabs, URLs, titles, and hibernation states are completely stripped from disk session flushes (session.json).
  • Instant toggle via keyboard shortcut (Ctrl + Shift + P) with subtle Tokyo Night rose theme accenting.
  • Automatic legacy workspace migration to "Private (old)" preventing tab loss from pre-existing profiles, alongside reserved system namespaces.

Comprehensive Four-Phase Security Hardening

Rigorous multi-layer defence-in-depth lockdown safeguarding userscript execution, guest webviews, and local system integration.

  • Userscript sandbox hardened with DNS pinning, net.BlockList protection against private and multicast subnets, payload bounding, and prototype pollution immunity.
  • Webview navigation locks: enforced will-navigate, setWindowOpenHandler, and isSafeTabUrl across guest and main windows.
  • Local filesystem protection: address bar local file access restricted strictly to genuine PDF viewing, and IPC download execution confined to tracked safe paths.
  • Safe content extraction: inert DOMParser context for Reader View distillation and sanitised Markdown hyperlink validation in Notes.

Electron v45.0.0 Runtime Modernisation

Updated core Electron and Chromium runtimes to stay ahead of upstream CVEs and leverage latest platform enhancements.

  • Upgraded runtime to Electron v45.0.0 with Chromium security patches, V8 optimisations, and improved memory efficiency.
  • Bundled FontAwesome locally to eliminate external font queries and enforce strict Content Security Policy (form-action 'none').
  • Google favicon leak prevention: unresolvable favicons cleanly return null instead of querying third-party endpoints.

Session Resilience & 52-Suite Test Harness

Enhanced crash protection, atomic state updates, and massive expansion of automated regression verification.

  • Session snapshot rotation: automatic timestamped snapshots (session.snap-*.json) and suspect blank session quarantine (session.suspect.json).
  • Atomic partial configuration updates and deduplicated event hooks in main/config.js.
  • Expanded automated test harness to 52 dedicated suites verifying security sandboxes, lifecycle teardowns, and atomic writes with 100% pass rate.

Your Voice Shapes Mise

Mise collects zero telemetry and never tracks your browsing. Because we do not monitor you, your direct feedback is the only way we know how the browser performs across different Linux distributions and desktop setups.
