What's New in Mise v1.4.0

The v1.4.0 Privacy Shield & Ephemeral Peek Update: Introducing the granular domain permission vault with Zero-Trust sensor isolation, transient Glance modal previews, DNS-over-HTTPS resolver controls, WebRTC privacy policies, workspace active tab persistence, and the latest Chromium/Electron 45.1.0 engine.

Granular Permission Vault & Zero-Trust Sensor Lockdown

Fine-grained per-domain access control for camera, microphone, geolocation, notifications, and clipboard sensors.

  • Dedicated Permissions Vault in Preferences (F1 or Ctrl + H) with search filtering, domain status cards, and individual or bulk access revocation.
  • Zero-Trust sensor lockdown in Private Profile (MisePrivateProfile): all sensor requests are blocked unconditionally to prevent fingerprinting leaks.
  • Quick status bar indicator and interactive popover displaying real-time domain permissions with instant toggle overrides.
  • Atomic disk persistence with automatic corruption recovery ensuring your privacy rules are never lost.

Ephemeral Tab Peek ("Glance")

Lightning-fast, keyboard-driven preview modal that inspects links without adding permanent tabs to your tab list.

  • Trigger instantaneously using Shift + Click or the gh link hint chord.
  • Detaches cleanly from the DOM on dismissal (Escape) with zero memory residue.
  • Promote any previewed link to a full permanent tab with a single keystroke (Enter).
  • Full sandboxing and isolated navigation guards prevent untrusted frames from breaking out.

DNS-over-HTTPS (DoH) Resolver

Protect domain lookups from local network eavesdropping and ISP tracking with encrypted DNS resolution.

  • Integrated privacy-focused providers: Cloudflare, Quad9, Google, and Mullvad.
  • Full support for custom RFC 8484 DoH HTTPS endpoints with input validation.
  • Dynamic resolver switching in Preferences without requiring a browser restart.

WebRTC Privacy Controls & Active Tab Persistence

Advanced leak prevention, enhanced workspace session restoration across restarts, and upstream engine updates.

  • Configurable WebRTC policies including default_public_interface_only and disable_non_proxied_udp to eliminate local IP address leakage.
  • Remembers active tab indexes per workspace, waking only your active tab on startup whilst keeping background tabs asleep.
  • Optimised native auto-step scrolling navigation.
  • Upgraded to Electron 45.1.0 with the latest Chromium security enhancements and Wayland stability improvements.
  • All 61 automated test suites passing with 100% verification across security, UI, and storage modules.

Your Voice Shapes Mise

Mise collects zero telemetry and never tracks your browsing. Because we do not monitor you, your direct feedback is the only way we know how the browser performs across different Linux distributions and desktop setups.
