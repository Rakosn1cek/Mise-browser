Quick Start Guide Offline Reference

Welcome to Mise Browser

A minimalist, privacy-focused, keyboard-centric web browser engineered for Linux desktops, window managers, and power users.

The Uncluttered Canvas Philosophy

Mise intentionally eliminates persistent address bars, bulky tab strips, and floating window controls from the browser canvas. Your web content occupies 100% of your screen estate, while the vertical sidebar auto-collapses into a slim icon strip. Every browser capability is accessible via fast keyboard chords or modal Vim commands.

Core Navigation & Daily Essentials

Address Bar & Search Bangs

Focus the centered status bar address bar from anywhere to navigate or query search engines.

  • Press Ctrl + L or o to focus the address bar.
  • Type a URL directly or enter search terms for DuckDuckGo.
  • Quick search bangs: prefix queries with g for Google, gh for GitHub, aur for Arch User Repository, or yt for YouTube.
  • Define and customise search aliases in Preferences (Ctrl + H).

Vim-Inspired Link Hints

Navigate hyperlinks and form controls effortlessly without touching a mouse or trackpad.

  • Press f to activate Link Hints mode.
  • Two-letter cyan badges appear across all clickable elements on the active page (highlighting in orange as you type).
  • Type the two hint letters to simulate an instant click.
  • Press Escape at any point to dismiss hint tags.

Tabs & Accidental Closure Guard

Organise your research with persistent workspaces, top-anchored pinned tabs, and memory saving hibernation.

  • Press Ctrl + T to open a new tab, and Ctrl + X to close the current tab.
  • Press Ctrl + 1 through Ctrl + 9 to jump straight to tabs 1 through 9.
  • Press Ctrl + Shift + X or p to pin essential tabs to the top with a golden badge.
  • Pinned tabs are protected against accidental closure: pressing Ctrl + X displays a status guard warning.
  • Background tabs hibernate automatically to preserve system memory.

Command Centre & Preferences

A unified searchable hub for all browser operations, settings, and diagnostic tools.

  • Press Ctrl + P to summon the Command Palette.
  • Filter any action by title or keywords with real-time fuzzy matching.
  • Press Ctrl + H (or F1) to access the 6-tab Preferences overlay.
  • Customise process limits, hardware switches, adblocking, and visual colours.

Power Tools & Advanced Features

Dual Split Comparison View

Compare documentation, pull requests, or articles side by side without tiling window manager complexity.

  • Press Ctrl + Shift + S to split the viewport into two 50% comparison panes.
  • Press Ctrl + O to switch keyboard focus between Pane 1 and Pane 2.
  • Press Ctrl + \ to swap the positions of the two open split panes instantly.

Distraction-Free Reader & Quick Notes

Distil messy web pages into clean typography and export highlights into Markdown notes.

  • Press e or F9 to toggle native distraction-free Reader View.
  • Press Ctrl + Shift + E to export the distilled article directly to Quick Notes.
  • Press Ctrl + N to view or edit your local Markdown scratchpad.
  • Notes are stored locally in plain text under your configuration directory.

Isolated Private Workspace

Browse in dedicated volatile memory with complete data isolation and zero disk footprint.

  • Press Ctrl + Shift + P to toggle the built-in Private Workspace instantly.
  • Ephemeral partition: cookies, storage, and network caches are purged completely upon closure.
  • Zero disk persistence: private tabs, URLs, and states are stripped from disk session flushes.
