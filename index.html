      Preferences

      Performance & Hardware (Requires Restart)

      Hardware GPU Acceleration Enables hardware-accelerated video decoding and rasterisation.
      Background Throttling Throttles timers and delays tasks in inactive tabs to save CPU and battery.
      Renderer Process Limit Hard caps background Chromium process forks.
      Tab Hibernation (Sleep Timeout) Detaches idle background tabs from memory while saving URL, title, and scroll position.
      Default Email Handler Choose between native OS mail client or a webmail compose provider.
      Default Search Engine
      Fallback provider for non-URL queries entered in the address bar.

      Appearance

      Dark Theme Layout Toggle between Tokyo Night dark theme and high-contrast light theme.

      Privacy & Protection

      Global Private Browsing Isolates navigation into an in-memory session partition.
      Active Site Data Clear session cache or surgical cookies for the current domain.
      Trusted Sites (Banking / Shopping) Sites listed here skip fingerprint randomisation, tracker blocking and permission blocking, since banks and checkout flows treat those protections as fraud signals. Every other site keeps full protection. One domain per line, e.g. yourbank.co.uk (subdomains are covered automatically). Applies immediately, no restart needed.
